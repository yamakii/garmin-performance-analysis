# Egress allowlist for the Claude Code sandbox container — single source of truth.

# One domain per line; `#` starts a comment. An entry allows the domain AND every
# subdomain (dnsmasq suffix match): `github.com` covers api.github.com, codeload…
# Only names listed here resolve inside the container (dnsmasq refuses the rest),
# and only the IPs they resolve to are reachable (init-firewall.sh ipset).
# The file is baked into the image: after editing, rebuild with docker/run.sh.
